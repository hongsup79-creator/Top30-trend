# TOP30 트렌드 대시보드 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 코스피+코스닥 등락률 상위 30종목을 매일 자동 수집해 섹터·시총·연속 등장 트렌드를 보여주는 정적 대시보드.

**Architecture:** GitHub Actions가 Python 스크립트로 네이버 업종·시세를 받아 `data/boards/YYYYMM.json`(일자별 TOP30)과 `data/summary.json`(메타·연속 등장)을 커밋. GitHub Pages의 `index.html`이 JSON을 읽어 기간별 집계를 브라우저에서 계산·표시.

**Tech Stack:** Python 3.11, pandas, requests, pytest; HTML + Chart.js 4 + SheetJS (CDN).

**Spec:** `docs/superpowers/specs/2026-11-17-top30-trend-design.md`

## Global Constraints
- 데이터 출처: `m.stock.naver.com/api/stocks/industry`, `fchart.stock.naver.com/sise.nhn` (Radar와 동일)
- 시총 구간 라벨: `1천억 미만`, `1천억~5천억`, `5천억~1조`, `1조 이상`
- 크론: `30 11 * * 1-5` (UTC) = 평일 20:30 KST
- 백필 70거래일, 평소 10거래일 재계산(최근 일자 덮어쓰기)

## Review Focus
1. 거래정지 후 재개 종목 — 직전 유효 종가 대비로 계산, NaN 행은 순위에서 빠져야 함.
2. 분할·병합으로 ±30% 초과 — 순위에서 제외.
3. 20:05 이전 실행 — 오늘 값 제외(확정 전).
4. 30종목 미만인 날(데이터 부족) — 있는 만큼만 저장, 오류 없음.
5. 업종 수집 실패 — 실행 실패로 끝나야 하며 기존 데이터를 지우면 안 됨.

### Task 1: 계산 로직 (`scripts/top30_core.py`)
**Interfaces (Produces):**
- `is_excluded(name: str) -> bool` — 스팩, 우선주(`우`, `우B`, `1우`, `2우B`, `우(전환)` 끝)
- `cap_bucket(cap_won: float) -> str`
- `daily_top(price: DataFrame[date×code], meta: dict[code→{name,sector,cap}], vol: DataFrame|None, n=30) -> dict[str(YYYYMMDD) → list[row]]`, row = `{rank, code, name, sector, chg(%), close, cap(원), amount(원), bucket}`
- `build_summary(boards: dict) -> dict` with `dates, months, latest_date, momentum, recurring`
  - momentum: 최신일 기준 연속 등장 `current_streak ≥ 2`, `max_streak`, 정렬 (current desc, max desc)
  - recurring: 전체 기간 등장 횟수 ≥ 2, count desc, 상위 50
- [ ] Tests in `tests/test_core.py`: 제외 규칙, 구간 경계(1e11 → `1천억~5천억`), 정지 후 재개, ±30.5% 제외, 시총 근사, 연속 등장 계산. 실행 `pytest -q` → PASS. Commit.

### Task 2: 수집·저장 스크립트 (`scripts/update_top30.py`)
**Consumes:** Task 1 함수. `--demo` 옵션은 가짜 데이터로 전체 파이프라인 실행.
- `fetch_industry()` / `naver_history()` — Radar 코드 재사용.
- `load_boards()` / `save_boards(boards)` — 월별 파일 병합, 기존 일자 보존.
- `main()` — count 결정(데이터 없으면 70, 있으면 10), 업종 1000종목 미만이면 예외로 종료.
- [ ] `python scripts/update_top30.py --demo` 실행 → `data/summary.json`·`data/boards/*.json` 생성 확인. Commit.
