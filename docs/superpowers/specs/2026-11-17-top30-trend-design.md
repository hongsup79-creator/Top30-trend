# TOP30 트렌드 대시보드 — 설계 (2026-11-17, 승인됨)

## 왜
매일 등락률 상위 30종목을 모아 보면 그날의 상승 종목과 섹터 흐름(트렌드)을 알 수 있다.
참고: jblee1031/top30-tracker-dashboard (몽당연필 게시글 기반). 우리는 시장 데이터로 자동 집계.

## 목표 / 비목표
- 목표: 코스피+코스닥 통합 등락률 상위 30종목을 매일 자동 수집, 섹터·시총 구간·연속 등장으로 트렌드를 보여줌. 휴대폰에서도 보기 좋게.
- 비목표(1차): 상승이유·테마 자동 생성(B안, 2~3주 사용 후 판단), 야간선물(바로가기 링크만).
- 반목표: 매일 수집이 자주 깨지는 구조, 사람 손이 가야 하는 구조.

## 접근
- A안(채택): 네이버 시세(fchart) + 네이버 업종 분류로 직접 계산. Stock Trend Radar와 같은 출처라 Actions에서 검증됨.
- B안(보류): A + 뉴스 제목 기반 AI 테마·상승이유. 유료 API·수집 불안정.
- C안(기각): 몽당연필 게시글. 접근 권한·유료 콘텐츠 공개 문제.
- Stock Trend Radar 탭이 아닌 별도 저장소: Radar는 기능 동결 후 실전 관찰 중.

## 결정 사항
- 대상: 네이버 업종 분류에 속한 전 종목(ETF·ETN 자연 제외). 스팩·우선주 제외 (Claude 판단: 우선주는 뉴스 없는 급등이 많아 트렌드를 흐림).
- 등락률 = 종가/직전 거래일 종가 − 1. ±30.5% 초과(분할·병합 등 기업행위)와 직전 종가 없음(신규상장) 제외.
- 과거 일자 시가총액 = 현재 시총 × 당일 종가/최근 종가 (주식 수 변화는 무시, 근사).
- 시총 구간: 1천억 미만 / 1천억~5천억 / 5천억~1조 / 1조 이상 (원본과 동일).
- 실행: 평일 20:30 KST (네이버 차트가 넥스트레이드 애프터마켓 20:00까지 반영 후 확정). 첫 실행 시 약 3개월(70거래일) 백필.
- 상승이유 대용: 종목명 클릭 → 네이버 증권 종목 뉴스.

## 화면
기준일·요약 → 오늘(선택일)의 TOP30 표 → 기간 선택(최근 20일/월/주/전체) → 섹터 막대(클릭 시 종목) → 일자×섹터 히트맵(클릭 시 종목) → 연속 등장 랭킹·반복 등장 종목 → 시총 구간 비중 변화 → 엑셀 다운로드. 야간선물 바로가기 버튼.
